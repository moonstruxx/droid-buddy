# add-visual-validation — evidence

Visual proof gallery for `add-visual-validation` (ephemeral worktree → durable archive).

## Source (ephemeral, gitignored)

- `evidence/gallery/index.html` — generated by `cargo run --bin snapshot-gallery` or `cargo test -- --generate-gallery`
- Per-scenario sidecars: `evidence/gallery/<scenario>_<theme>.ansi` and `.html` (same `buffer_to_html` as insta snapshots)

`evidence/gallery/` is `.gitignore`'d (`/evidence/` at repo root) and not committed to `master`. CI uploads it as an artifact.

## Durable copies (committed)

- **Staged**: `openspec/changes/add-visual-validation/evidence/gallery/` — mirror of ephemeral gallery, checked in so `openspec archive add-visual-validation` (which copies the whole change folder) carries evidence into the archive automatically.
- **Archive**: `openspec/changes/archive/add-visual-validation/evidence/gallery/` — final durable location after archive. The script also handles dated archive variants (`*add-visual-validation`).

## Archiving

```bash
# Regenerate ephemeral gallery
cargo run --bin snapshot-gallery

# Stage + archive (idempotent)
./scripts/archive-gallery.sh

# Stage only (before running openspec archive)
./scripts/archive-gallery.sh --stage-only

# Then archive via OpenSpec CLI
openspec archive add-visual-validation --skip-specs  # or without flag once specs are ready
# Verify
ls openspec/changes/archive/add-visual-validation/evidence/gallery/index.html
openspec archive --help
```

`./scripts/archive-gallery.sh` is the single source of truth for copying; it re-generates the gallery if `evidence/gallery/index.html` is missing and verifies both staged and archive destinations.

## Why this layout

OpenSpec's `archive` copies `openspec/changes/<name>/` into `openspec/changes/archive/<name>/`. By committing a mirror under the change folder, evidence survives archive without a custom hook. The script provides both the pre-archive staging step and a direct post-archive copy for manual verification.
